快速 开始

几分钟内启动你的 AI Agent

01

📥 下载安装

从 GitHub Releases 下载对应平台二进制，或通过 Go、Docker 安装。

# 一键安装 (Linux/macOS)
curl -fsSL https://raw.githubusercontent.com/
  magicwubiao/go-magic/main/scripts/install.sh | bash
02

🔧 初始化配置

运行交互式配置向导，设置 API Key 和 AI 提供商。

magic setup
03

💬 开始聊天

使用 TUI 界面或 Web Dashboard 与 AI Agent 交互。

magic chat   # TUI 模式
magic server # Web Dashboard

Coding 模式

Chat 模式 vs Coding 模式，按需切换

特性 Chat 模式 Coding 模式
文件写入权限 受限 宽松
命令超时时间 30s 300s
代码执行 禁用 ✅ Python / Node.js
自动审批工具 否 ✅ 是
💡 使用 /mode coding 或 /mode chat 切换
