# Business Email Guide

How to write emails that get read, understood, and answered.

## When to Use

Load this skill when:
- Drafting a request, follow-up, status update, or announcement
- Replying to a client, colleague, or vendor
- Softening or firming up the tone of a draft
- Writing a difficult email (delay, rejection, escalation)

## Quick Reference

### Structure
```
Subject   topic + action needed ("Approval: Q4 budget by Fri")
Greeting  name; match the relationship's formality
Opening   why you are writing, in one sentence
Body      the ask, the context, the deadline
Closing   what happens next + who does it
Sign-off  regards / thanks + name
```

### Subject line patterns
```
Request:   "Request: design review for v2 by Thursday"
Update:    "Update: migration finished, zero downtime"
Deadline:  "Action needed: sign contract before 5/20"
Question:  "Quick question: vendor invoice #1042"
```

## The rules

1. **The ask goes first.** State what you need in the first two lines;
   context follows, never leads.
2. **One email, one topic.** Two asks in one email halves the reply rate
   for both.
3. **Deadlines are explicit.** "By Friday 5 PM" — never "ASAP" or "soon".
4. **Match formality to the relationship,** and stay consistent once set.
5. **Bad news: direct but kind.** Lead with the decision, then the reason,
   then the alternative if one exists.

## Templates

### Follow-up (no reply yet)
```text
Subject: Following up: proposal feedback?

Hi [Name],

Following up on the proposal I sent last Tuesday — do you have any
feedback, or should I assume the current version stands?

If it helps, I can walk through the key points in a 15-minute call
this week.

Thanks,
[Name]
```

### Request with deadline
```text
Subject: Action needed: approve Q4 budget by Friday

Hi [Name],

Could you approve the attached Q4 budget by Friday 5 PM? The vendor
needs confirmation before Monday to lock in current pricing.

The only change from last draft is the training line item (now ¥18,000).

Happy to answer any questions before Friday.

Best regards,
[Name]
```

### Delay / bad news
```text
Subject: Update: delivery moved to March 12

Hi [Name],

The delivery date has moved from Feb 26 to March 12. The cause was
[specific reason], and we have [mitigation] in place to prevent a
repeat.

I know this affects your launch plan — let's discuss the options on
tomorrow's call if the new date is a problem.

Sorry for the inconvenience,
[Name]
```

## Tone ladder

| Situation        | Instead of                | Write                          |
| ---------------- | ------------------------- | ------------------------------ |
| Chasing          | "Why haven't you replied" | "Circling back on …"           |
| Disagreeing      | "That's wrong"            | "One concern: …"               |
| Declining        | "We can't do that"        | "We're not able to, because …" |
| Urgent           | "URGENT!!!"               | "Time-sensitive: … by [date]"  |

## Pitfalls

- Reply-all by default is wrong; default to the sender.
- Never send when angry — draft, wait, reread the next morning.
- Attachments: name files clearly (`Q4-budget-v3.xlsx`), mention them
  in the body.
- Do not put confidential details in the subject line.

## Delivery checklist

- [ ] Subject says the topic and the action
- [ ] The ask is in the first two lines with an explicit deadline
- [ ] Next step + owner stated in the closing
- [ ] Read once aloud for tone before sending
