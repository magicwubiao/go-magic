# 10 · 即时设计（JsDesign）画布桥接

即时设计官方没有公共远程 MCP，给的是**画布桥接**：本地 `npx` 进程用 WebSocket 连**客户端里的 MCP Bridge 插件**，再由插件操作画布。

> **为什么不在内置目录里？**
> 它依赖本机装着即时设计客户端、并且那个 Bridge 插件启用着。go-magic 跑在服务器上时 `npx -y jsdesign-mcp` 能起来、但永远连不到画布——内置进目录只会让用户以为是自己配错了。

## 前置条件

1. 本机装 **Node**（提供 `npx`）；
2. 装**即时设计客户端**并打开要操作的画布（浏览器版没有 Bridge 插件）；
3. 客户端里安装并启用 **MCP Bridge** 插件；
4. 装本插件并连接。

```bash
magic plugin install ./examples/plugins/10-mcp-jsdesign
```

## 失败长什么样

| 现象 | 原因 |
|---|---|
| 连接超时 / 进程立刻退出 | `npx` 不在 PATH，或拉包失败（内网/代理） |
| 连上了但工具列表为空 | 客户端没开，或 MCP Bridge 插件没启用 |
| 工具调用报 WebSocket 连接失败 | 画布没打开（插件只在有打开文档时才连） |
